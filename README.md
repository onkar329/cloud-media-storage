# Cloud Based Media Files Storage Service

A Google Drive-style cloud media/file storage MVP based on the supplied project specification.

## Repositories
The project is intentionally split into:
- `frontend` — Next.js + TypeScript + Tailwind
- `backend` — Node.js + Express + TypeScript + Supabase

## MVP
Authentication, folders, file upload/download, sharing, public links, search, stars, trash/restore.

## Start
See `frontend/README.md` and `backend/README.md`.

The GitHub repositories must be created under your GitHub account. This package is ready to push as two separate repositories.
